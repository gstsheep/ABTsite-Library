# 冰水系統 CFC（CHSYS）

來源：`docs/reference/CHSYS.pdf`（TIA Portal 匯出，冰水系統 - Partition_1，Task：OB1，共 7 頁）。

> 標記說明：「接線」欄位依 CFC 圖面判讀；「功能說明」中標示【推定】者，是依模塊腳位名稱推論，CFC 內部邏輯未於附件呈現，請以 Library 實際模塊為準。

---

## 1. 架構總覽

```
OB1 / Partition_1
├── 1.1  系統層：總系統起停 → 冰機順位比較 → 加減機 (AddnSub) → SYS1~SYS6
├── 1.2  系統 1：保護機制 / 跳脫機制 / 系統階段啟動 (Sys.rs_1)
├── 2.1  共用：水塔狀態、水塔 OL → 各系統保護 / 跳脫
├── 2.2  系統 2：保護機制 / Overload configuration / System run step (Sys.rs_2)
├── 3.1  （空白頁，保留擴充）
└── 3.2  系統 3：保護機制 / Overload configuration / System run step (Sys.rs_3)
```

範例展開 3 組系統；模板最多支援 6 組（SYS1~SYS6）。

## 2. 系統層模塊

### 2.1 總系統起停點（CMD_B）

| 腳位 | 方向 | 接線 |
|---|---|---|
| EnIn1 / ValIn1 / PrioIn1 | 輸入 | 命令輸入（CC / 排程） |
| PrVal | 輸出 | → 加減機 `StartStop` |

### 2.2 冰機順位比較模塊（CFC）

| 腳位 | 方向 | 說明 |
|---|---|---|
| En1 ~ En6 | 輸入 | 第 n 台冰機是否可用（預設 0） |
| CH1 ~ CH6 運轉時數 | 輸入 | 累計運轉時數（預設 16#00000000） |
| CH1 ~ CH6 效率 | 輸入 | 冰機效率（預設 0.0） |
| CH6 Oph | 輸入 | 第 6 台運轉時數（Operating hours） |
| 順位1冰機 ~ 順位6冰機 | 輸出 | → 加減機 `Sq1 ~ Sq6` |

功能說明【推定】：在可用（En = 1）的冰機中，依運轉時數與效率排序，輸出啟動順位，達到輪替與均衡運轉。

### 2.3 Add-ons and Subtractions（加減機，實例 AddnSub）

| 腳位 | 方向 | 接線來源 / 去向 | 型別 |
|---|---|---|---|
| StartStop | 輸入 | 總系統起停點 PrVal | CMD_B |
| Num | 輸入 | 可運轉系統數量 | W_DINT |
| T | 輸入 | 冰水總回水溫度計 | R_A |
| T Add-on | 輸入 | 加機溫度（預設 0.0，TshVal 0.1） | W_A |
| T Sub-dn | 輸入 | 減機溫度（預設 0.0，TshVal 0.1） | W_A |
| Sq1 ~ Sq6 | 輸入 | 冰機順位比較模塊 順位1~6 | — |
| Add time | 輸入 | 加機間隔 | W_DINT |
| Sub time | 輸入 | 減機間隔 | W_DINT |
| Op Num | 輸出 | 目前運轉系統數 | — |
| SYS1 ~ SYS6 | 輸出 | → 各系統 `Sys.rs_n."system ON/OFF"` 及 `Prt.Cnf_n.系統起停` | — |

功能說明【推定】：

- StartStop = ON 時，依冰水總回水溫度 T 判斷加減機。
- T ≥ 加機溫度且持續達加機間隔，且運轉數 < Num → 依順位啟動下一組系統。
- T ≤ 減機溫度且持續達減機間隔 → 依順位關閉一組系統。
- StartStop = OFF → SYS1~SYS6 全部 OFF。

## 3. 每組系統模塊（n = 1…6）

每組系統由三個 CFC 組成，命名規則如下：

| 模塊 | 實例名稱 | 頁面標題 |
|---|---|---|
| 保護機制 | `Prt.Cnf_n` | 保護機制 |
| 跳脫機制 | `OL.Cnf_n` | 跳脫機制 / Overload configuration |
| 系統階段啟動 | `Sys.rs_n` | 系統階段啟動 / System run step |

### 3.1 每組系統所需點位

| 點位 | 型別 | 去向 |
|---|---|---|
| SYSn 維修點 | W_B | 保護機制 `維修點` |
| CHPn 狀態 | R_B | 保護機制 `冰水泵狀態` |
| CHPn 流量開關 | R_B | 保護機制 `冰水流量開關` |
| CWPn 狀態 | R_B | 保護機制 `冷卻水泵狀態` |
| CWPn 流量開關 | R_B | 保護機制 `冷卻水流量開關` |
| CHPn 跳脫 | R_B | 跳脫機制 `冰水泵OL` |
| CWPn 跳脫 | R_B | 跳脫機制 `冷卻水泵OL` |
| CHn 跳脫 | R_B | 跳脫機制 `冰機OL` |
| SYSn 確認時間 | W_DINT | 保護機制 `開機確認時間`、系統階段啟動 `開機確認時間` |
| SYSn 除冷時間 | W_DINT | 系統階段啟動 `關機除冷間隔` |

跨頁連接（Interconnection）：

| 來源 | 去向 |
|---|---|
| `…/AddnSub.SYSn` | 保護機制 `系統起停`、系統階段啟動 `system ON/OFF` |
| `…/水塔狀態.PrVal` | 保護機制 `水塔狀態` |
| `…/水塔OL.PrVal` | 跳脫機制 `水塔OL` |

### 3.2 保護機制（Prt.Cnf_n）

| 腳位 | 方向 | 說明 |
|---|---|---|
| 系統起停 | 輸入 | AddnSub.SYSn |
| 開機確認時間 | 輸入 | SYSn 確認時間 |
| 維修點 | 輸入 | SYSn 維修點 |
| 冰水泵狀態 / 冰水流量開關 | 輸入 | CHPn |
| 冷卻水泵狀態 / 冷卻水流量開關 | 輸入 | CWPn |
| 水塔狀態 | 輸入 | 共用水塔狀態 |
| status | 輸出 | → 系統階段啟動 `Protection CFC` |

功能說明【推定】：系統起停後，在開機確認時間內檢查泵狀態、流量開關與水塔狀態是否回饋；維修點啟用或回饋不符時，status 判定異常。

### 3.3 跳脫機制（OL.Cnf_n / Overload configuration）

| 腳位 | 方向 | 說明 |
|---|---|---|
| 冰水泵OL | 輸入 | CHPn 跳脫 |
| 冷卻水泵OL | 輸入 | CWPn 跳脫 |
| 水塔OL | 輸入 | 共用水塔 OL |
| 冰機OL | 輸入 | CHn 跳脫 |
| OL | 輸出 | → 系統階段啟動 `Alarm CFC` |

功能說明【推定】：任一設備跳脫即輸出 OL。

![保護與跳脫](../flowcharts/06-protection-trip.svg)

### 3.4 系統階段啟動（Sys.rs_n / System run step）

| 腳位 | 方向 | 說明 |
|---|---|---|
| system ON/OFF | 輸入 | AddnSub.SYSn |
| Protection CFC | 輸入 | 保護機制 status |
| Alarm CFC | 輸入 | 跳脫機制 OL |
| 開機確認時間 | 輸入 | SYSn 確認時間 |
| 關機除冷間隔 | 輸入 | SYSn 除冷時間 |
| 冰水泵系統 | 輸出 | 冰水泵起停 |
| 區域泵系統 | 輸出 | 區域泵起停 |
| 冷卻水泵系統 | 輸出 | 冷卻水泵起停 |
| 水塔系統 | 輸出 | 水塔系統起停（→ 冷卻系統） |
| 冰機起停 | 輸出 | 冰機起停 |

功能說明【推定】：依輸出腳位順序分段啟動（冰水泵 → 區域泵 → 冷卻水泵 → 水塔 → 確認後冰機）；關機時先停冰機，經除冷間隔後再停泵與水塔，避免蒸發器 / 冷凝器殘餘冷量造成凍結或高壓。

![系統階段啟動](../flowcharts/05-chws-run-step.svg)

## 4. 參數設定建議表

| 參數 | 型別 | 範例預設 | 建議範圍【參考值，依案場調整】 |
|---|---|---|---|
| 可運轉系統數量 | W_DINT | 0 | 1 ~ 實際冰機台數（≤ 6） |
| 加機溫度 | W_A | 0.0 | 冰水回水設計值 + 0.5 ~ 1.0 °C |
| 減機溫度 | W_A | 0.0 | 冰水回水設計值 − 1.0 ~ 2.0 °C |
| 加機間隔 | W_DINT | 0 | 依控制器時間單位設定，通常 10 ~ 20 分鐘 |
| 減機間隔 | W_DINT | 0 | 通常 15 ~ 30 分鐘 |
| SYSn 確認時間 | W_DINT | 0 | 泵啟動至流量穩定時間，通常 60 ~ 180 秒 |
| SYSn 除冷時間 | W_DINT | 0 | 冰機停機後泵延時，通常 3 ~ 10 分鐘 |
| SYSn 維修點 | W_B | 0 | 維修時設 1，系統不參與加減機 |

> 參數預設值為 0，下載前必須依案場設計值設定，否則加減機與確認時間將失效。時間單位請以模塊說明為準。

## 5. 擴充至 4~6 組系統

1. 複製一組系統頁面（例如 1.2 頁）。
2. 實例名稱依序改為 `Prt.Cnf_n`、`OL.Cnf_n`、`Sys.rs_n`。
3. 將 `AddnSub.SYSn` 接至新系統的 `系統起停` 與 `system ON/OFF`。
4. 建立該組的 CHPn / CWPn / CHn 點位並接線。
5. 將共用 `水塔狀態`、`水塔OL` 接至新系統。
6. 於冰機順位比較模塊啟用 `En n` 並接入運轉時數、效率。
7. 更新 `可運轉系統數量`。
